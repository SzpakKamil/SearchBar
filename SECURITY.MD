# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| 1.0.0   | :x:                |

## Reporting Issues

### Security Vulnerabilities

Report security vulnerabilities to **dev@kamilszpak.com**. Include:

1. Description
2. Reproduction steps
3. Affected version
4. Potential impact
5. Fix suggestions (optional)

I request a 90-day disclosure deadline. I will acknowledge reports within 48 hours.

### UI Bugs

Report UI issues, layout problems, or interaction bugs via [GitHub Issues](https://github.com/SzpakKamil/SearchBar/issues).

1. Include screenshots or videos when possible.
2. Note the platform and OS version.
3. List steps to reproduce.

### Feature Suggestions

Propose features via GitHub Issues ("enhancement" label). Describe the functionality and use case.

## Best Practices

1. **Update**: Use the latest version.
2. **Sanitize**: Validate search input before passing it to queries or APIs.
3. **Privacy**: Avoid persisting search queries without user consent.

## Commitment

- Addressing security concerns promptly.
- Fixing UI bugs in a timely manner.
- Considering all feature proposals.
- Maintaining transparency about issues.

## Updates

Updates appear as new package versions with release notes.
